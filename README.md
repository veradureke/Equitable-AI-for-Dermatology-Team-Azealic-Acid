# Equitable AI for Dermatology Team Azealic Acid
> Team Members: Janelle Chan, Vera Dureke, Ena Macahiya, Natasha Prabhoo, Shreya Vallala

This repository contains our team’s submission for the Equitable AI for Dermatology Kaggle competition.
Our goal was to build a machine learning model capable of classifying skin conditions across diverse skin tones using a subset of the Fitzpatrick17k dataset.

## Summary
- Trained image classification models to identify 21 skin conditions.
- Explored dataset distributions, label imbalances, and skin tone representation.
- Applied transfer learning techniques for improved accuracy.
